# Keyboard Shortcuts

Shortcuts work in Clustta Desktop when the relevant view has focus. Use **Ctrl** on Windows and Linux, or **Cmd** in its place on macOS. On Mac keyboards, Alt is usually labelled Option.

## File & Project Management

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New project |
| `Ctrl+Alt+S` | Sync project |
| `Delete` in the project list | Remove the selected project through its removal controls |

## Content Creation

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | New collection |
| `Ctrl+T` | New asset from a template |
| `Ctrl+L` | New web link |
| `Ctrl+G` | Group selected items |

## Item Operations

| Shortcut | Action |
|----------|--------|
| `F2` | Rename selected item |
| `Ctrl+F2` | Edit selected item metadata |
| `Enter` | Open or enter selected item |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy, cut, or paste items |
| `Ctrl+D` | Duplicate asset |
| `Ctrl+F` | Fetch selected item |
| `Ctrl+Shift+F` | Build asset with dependencies |
| `Delete` | Free local file space while keeping history |
| `Shift+Delete` | Send item to trash |

## Versioning

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+C` | Create checkpoint |

## Navigation & Search

| Shortcut | Action |
|----------|--------|
| `F3` | Open search |
| `F5` | Reload current view |
| `Ctrl+I` | Open or close Agent console |
| `Ctrl+E` | Toggle file extensions |
| `Ctrl+P` | Toggle full paths |
| `Ctrl+U` | Toggle UI lock |
| `Ctrl+Shift+H` | Collapse collections |
| `Esc` | Cancel or close the current interaction |

Context menus and tooltips show shortcuts beside available actions. Permissions, selection, file state, and the active view determine whether an action can run; a shortcut does not bypass those requirements. For Agent composer commands and references, see [AI Agent](../features/ai-agent.md#setting-it-up).
